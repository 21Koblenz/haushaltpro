# Contributing to HaushaltPro

Contributions are welcome.

By contributing code or documentation, you agree that your contribution may be distributed as part of HaushaltPro under **AGPL-3.0-or-later**.

## Requirements

- Keep commits focused and understandable.
- Add or update tests for calculation changes and bug fixes.
- Use demo data only; never commit real household or bank data.
- Preserve mobile usability when changing tables, forms or navigation.
- Document new configuration, migrations and security-relevant behavior.
- State how a pull request was tested.
- AI-assisted contributions are allowed, but the contributor remains responsible for the result.

## Pull request checklist

Describe what changed, why it changed, how it was tested, which edge cases were covered and whether installation/database/configuration changes are required.
