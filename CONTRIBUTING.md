# Contributing to HaushaltPro

Contributions are welcome under the same copyleft terms as the project.

## License

By contributing code or documentation, you agree that your contribution can be distributed as part of HaushaltPro under **AGPL-3.0-or-later**.

## Development rules

- Keep commits focused and understandable.
- Do not mix unrelated refactoring with functional changes.
- Add or update tests for calculation logic and bug fixes.
- Use demo data only; never commit real bank exports or household data.
- Preserve mobile usability when adding columns, tables or controls.
- Document new configuration and migration steps.
- Mark behavior-changing changes in the changelog.

## Pull requests

A pull request should explain:

1. what changed;
2. why it changed;
3. how it was tested;
4. which edge cases were covered;
5. whether installation, database or configuration changes are required.

AI-assisted contributions are allowed. The contributor remains responsible for reviewing and testing the submitted result.
